# Tic Tac Toe Game 🎮

This is a simple Tic Tac Toe game project created to practice core programming concepts and logical thinking. The game is played on a 3×3 grid where two players take turns marking positions. It checks for winning conditions, draws, and invalid moves using clean and beginner-friendly logic. This project demonstrates the use of loops, arrays, and conditional statements and is ideal for learning and portfolio showcasing.
